# Course Glossary — a Claude Code practice project

A tiny, dependency-free Python tool that looks up course terms. No installs
needed beyond Python itself.

- Look up a term: `python glossary.py token`
- Run the checks: `python test_glossary.py`

You'll use this project in the **Getting Started with Claude Code** tutorial.
One check fails on purpose — you'll fix it with Claude Code, review the diff,
and watch the check turn green.
